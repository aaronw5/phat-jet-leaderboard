Glossary — what the model names mean
  • N: number of leading constituents fed to the model (kT-sorted unless marked pT-sorted).
  • patch attention (P, heads): PHAT-JeT's exact self-attention inside groups of P consecutive particles; "on leading K" = only the K hardest particles go through attention, the rest bypass it.
  • Linformer attention (k): keys/values compressed from N particles to k rows with fixed (constant-weight) projections, so the attention is N×k instead of N×N.
  • no attention: both attention blocks removed; the model is embedding → GMP → token mixing → FFN → pooling → head (no activation×activation multiplies at all).
  • global stage: how patches talk to each other — patch-token attention (paper), constant token mixer (a fixed-weight MLP over the patch tokens), mean-token broadcast, or none.
  • GMP: geometric message passing on a static (η,φ) grid — G×G grid (2-D), separable (two 1-D passes, ~8× cheaper), or none.
  • QAT → X EBOPs: quantization-aware training (HGQ2) with the bit-operation budget steered to X; distilled = trained against a float teacher's outputs; attention protected = minimum bit widths on the attention lanes.
  • Stage: f* = float screens, q* = quantized (QAT) runs. The small grey tag is the internal run id.
